Despliegue en AWS

Recursos del Learner Lab y qué regla de red permite cada conexión.

  • La sesión del laboratorio dura unas 4 h: al terminar, la EC2 se detiene. Con la Elastic IP asociada la dirección de la API no cambia entre reinicios. Los contenedores usan restart: unless-stopped y los datos viven en volúmenes nombrados, así que el stack vuelve solo al iniciar la EC2 (reinicio probado: IT-ENV-05, IT-ENV-08, IT-NFR-07).
  • Los tokens de InfluxDB se crean al inicializar el volumen: la API recibe uno de lectura y escritura y Grafana uno de solo lectura, cada uno en su propio volumen.
  • Detén la EC2 al cerrar cada sesión para no consumir presupuesto. Los tipos de instancia disponibles pueden variar por laboratorio.
  • Pasos de creación y comprobación en docs/deploy_ec2.md y scripts/smoke_env.sh (incluye --externo para el caso rojo).
