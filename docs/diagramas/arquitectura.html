Arquitectura bajo prueba

Quién habla con quién, por dónde cruza la red y qué tramo cubre cada nivel de prueba.

  • N1 sensor↔ESP32 · N2 ESP32↔red/API · N3 API↔BD · N4 recorre todo el camino · N0 verifica el entorno AWS y el stack Docker · N5/N6 se aplican sobre todo el conjunto.
  • La hora llega por NTP directamente a Internet, no pasa por la API: si falla, la lectura se guarda con ts_dispositivo = null.
  • Sin Elastic IP, la dirección de la EC2 cambia al reiniciar y el firmware debe actualizarse (riesgo R-01).
